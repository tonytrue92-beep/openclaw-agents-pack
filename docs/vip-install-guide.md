## ⚠️ Что должно быть ДО установки

1. **OpenClaw с первой недели курса** — если ещё не ставили, сначала первый
   установщик. Команда из материалов недели 1.
2. **Оплачен Pro (VIP) тариф** — если ещё нет, пишите в поддержку.
3. **Telegram-боты** через `@BotFather` — по одному на каждого агента,
   которого будете ставить (до 8). Названия любые: «Мой Технарь»,
   «Мой Маркетолог» и т.д. Сохраните токены.
   > ⚠️ **Не создавайте всех ботов подряд за минуту** — Telegram может
   > заблокировать создание на ~сутки. Партиями по 2-3 с паузой.
4. **Ваш Telegram user ID** — узнать через `@userinfobot` (напишите ему что угодно,
   он пришлёт ваш ID).

Если хоть одного пункта нет — сделайте сначала. Без них установщик не запустится.

## Шаг 1. Получите VIP-токен (1 минута)

1. Откройте в Telegram бота **[@AITeamVIPBot](https://t.me/AITeamVIPBot)**
2. Напишите `/start`
3. Введите **email** или **телефон**, которыми вы оплачивали VIP-тариф
4. Бот пришлёт токен вида:
   ```
   VIP-A7D2E8C09F1B4A3D-123456789-eyJhbGciOi...<длинная строка>
   ```
5. Скопируйте его — нужен на шаге 3.

### 🔒 Критически важно

> Пишите боту `@AITeamVIPBot` с того же Telegram-аккаунта, с которым будете
> писать вашим AI-агентам. **Токен привязан к вашему Telegram-аккаунту** —
> это защита от шаринга. Если получите токен с одного TG, а ставить будете
> с другого — установщик откажет.

## Шаг 2. Запустите установщик (1 минута)

### 🍎 На macOS — DMG (рекомендуется для не-технических клиентов)

Если не хочется работать с командной строкой — скачай **`OpenClaw-Setup.dmg`**
с [последнего релиза](https://github.com/tonytrue92-beep/openclaw-agents-pack/releases/latest)
и запусти 2 файла внутри двойным кликом. Полный пошаговый гайд:
[`docs/mac-install-guide.md`](./mac-install-guide.md).

Если предпочитаешь команды в терминале — продолжай ниже.

### На macOS / Linux / VPS

Откройте терминал:
- **На Mac**: `Cmd + Space` → `Терминал` → Enter
- **На Linux**: `Ctrl + Alt + T`
- **На VPS**: подключитесь по SSH

**Команда (стабильная сеть):**

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/tonytrue92-beep/openclaw-agents-pack/main/scripts/install-agents.sh)
```

**Если на корпоративной сети / VPS / VPN это вылетает с timeout** —
используй **self-contained bundle** (один файл, без зависимости от
`raw.githubusercontent.com`):

```bash
bash <(curl -fsSL https://github.com/tonytrue92-beep/openclaw-agents-pack/releases/latest/download/install-agents-bundled.sh)
```

Bundle публикуется автоматически при каждом релизе. Версия совпадает
с последним тегом. Internal-логика та же — просто один файл вместо
6 nested curl'ов.

### 🪟 На Windows — другой путь!

**Не запускайте эту команду в PowerShell** — она написана на bash и
требует Git Bash или WSL. Также **OpenClaw на Windows ставится не
этим bash-скриптом**, а нативным `.exe` installer'ом.

**Краткая последовательность для Windows:**

1. Установить **Git Bash** — [git-scm.com/download/win](https://git-scm.com/download/win) (next-next-install)
2. Установить **OpenClaw** нативно — [openclaw.ai/download/windows](https://openclaw.ai/download/windows)
3. В **PowerShell** настроить main-агента:
   ```powershell
   openclaw.cmd configure
   openclaw.cmd gateway start
   openclaw.cmd channels status --probe   # должно быть зелёное
   ```
4. В **Git Bash** (не PowerShell!) запустить наш установщик:
   ```bash
   git clone https://github.com/tonytrue92-beep/openclaw-agents-pack
   cd openclaw-agents-pack
   bash scripts/install-agents.sh
   ```

> 📘 **Полный гайд по Windows** со скриншотами, типичными проблемами
> и FAQ — в [`docs/windows-install-guide.md`](./windows-install-guide.md).
> Содержит 7 правил из реального успешного кейса — обязательно прочти
> перед установкой.

Нажмите Enter после команды установщика. Установщик запустится и покажет меню.

## Шаг 3. В меню выберите **«3) Pro — 8 агентов»** (5-8 минут)

> В актуальном меню: **1) OpenClaw · 2) Base · 3) Pro**. Pro — пункт **3**
> (обычно достаточно просто нажать Enter — установщик сам подскажет твой
> тариф по токену).

Установщик проведёт вас по шагам, нужно будет:

1. **Вставить Pro-токен** — тот, что прислал `@AITeamVIPBot`
2. **Выбрать модель AI** (шаг R1) — Enter = бесплатная (карта не нужна)
3. **Выбрать агентов** — список из 8 с номерами: введи номера через пробел
   (например `1 2 7`) или **Enter — поставить всех 8**
4. **Ввести Telegram bot tokens** (шаг R2) — по одному на каждого
   выбранного агента, по очереди
5. **Подтвердить ваш Telegram ID** (шаг R2.5) — обычно берётся автоматически

### 💡 Совет

**Заранее запишите** где-то под рукой, какой токен от какого бота — скрипт
будет спрашивать их по порядку, и если перепутаете (токен от Маркетолога
для Технаря) — все сообщения уйдут не к тому агенту.

## Шаг 4. Проверка (1 минута)

Когда установщик закончит — откройте Telegram, найдите любого из ваших
ботов (установщик напишет их `@username` в финале) и напишите `/status`.

### 💡 Про онбординг

При первом сообщении Дизайнер / Координатор / Копирайтер **сами спросят
5-6 коротких вопросов** про вашу нишу, ЦА и тон. Это нормально — агент
записывает ответы в свою память и потом отвечает с учётом контекста, а
не «обобщённо». Пройдите онбординг один раз, дальше работа пойдёт быстрее.

Должен ответить в течение 5-10 секунд. Если ответил — **всё работает!** 🎉

Напишите ему обычное сообщение — получите ответ AI.

## 🆘 Если что-то пошло не так

### «Токен не прошёл проверку»

Скопируйте токен ещё раз целиком из `@AITeamVIPBot`. Проверьте что в нём
**три секции через дефис** и последняя (подпись) не обрезана. Формат:
`VIP-XXXX...XXXX-ЦИФРЫ-длинная_строка`.

### «Этот токен выдан для другого TG»

Вы пишете боту `@AITeamVIPBot` с одного Telegram-аккаунта, а устанавливаете
с другого. Откройте `@AITeamVIPBot` с **того же TG**, который используете
для AI-агентов, получите новый токен.

### «Не нашёл настройки OpenClaw»

Сначала нужен первый установщик (материалы недели 1). Запустите его,
подключите один базовый Telegram-канал — и вернитесь сюда.

### «declare: -A: invalid option» или странная ошибка bash

Старая версия bash на macOS (3.2). Установщик должен сам поставить
новую через Homebrew. Если не получилось — выполните:
```bash
brew install bash
```
и запустите установщик снова.

### Ничего из этого не помогло

Соберите debug-bundle и пришлите в саппорт:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/tonytrue92-beep/openclaw-agents-pack/main/scripts/install-agents.sh) --collect-debug
```

Zip-файл появится в `~/openclaw-agents-pack-debug-*.zip`. Все секреты в
нём замаскированы — можно смело пересылать.

## ❓ Частые вопросы

**Что если я хочу сменить Telegram-аккаунт?**
Напишите в саппорт. Мы обновим привязку токена к новому TG ID, и
старый токен перестанет работать.

**Могу ли я установить VIP на два компьютера (ноут + VPS)?**
Да. На обоих используйте один и тот же VIP-токен и тот же Telegram-аккаунт.
Каждая машина будет независимой инсталляцией.

**Что если у меня уже стоят 3 агента (Base)?**
Запустите установщик, выберите «3) Pro», в списке агентов выберите кого
добавить (или Enter — всех). Установщик увидит апгрейд и предложит
**«Дополнить»** — добавятся недостающие, уже стоящие не трогаются
(MEMORY сохраняется).

**Что если у меня стоит часть Pro-агентов?**
То же самое: установщик предложит **«Дополнить»** по умолчанию — нажмите
Enter, доустановятся только недостающие из выбранных. Чтобы обновить
шаблоны уже стоящих — запустите **`--refresh-templates`** (см. ниже).

**Как обновить шаблоны (новые SOUL/LEARNING/skills) без потери памяти?**
Запустите:
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/tonytrue92-beep/openclaw-agents-pack/main/scripts/install-agents.sh) --refresh-templates
```
Установщик найдёт все установленные агенты и обновит **только системные**
шаблоны (IDENTITY, AGENTS, SOUL, LEARNING, skills). Ваши `MEMORY.md`
(контекст сессий) и `USER.md` (ответы онбординга) **не тронутся**.
Старые файлы бэкапятся в `~/.openclaw/workspace-<agent>/.backups/<timestamp>/`
на случай отката.

То же самое можно получить интерактивно: запустить установщик без
флагов → меню → выбрать набор → на шаге R0 выбрать «**1) Обновить
шаблоны**» (default).

**Что такое embedding-память и зачем включать?**
Без embedding агент при каждом ответе перечитывает `MEMORY.md` целиком.
Через 2-3 месяца там будет 50+ КБ контекста — бот станет медленнее и
дороже. С embedding он ищет в памяти **семантически** — находит
«ты говорил про лендинг неделю назад» даже если сейчас спрашиваешь
по-другому. Стоимость ≈$0.13 за 1M токенов = копейки в месяц.
Установщик в шаге **R1.5** даст выбор «включить / без embedding» с
коротким объяснением. Можно использовать тот же OpenAI-ключ что для
chat-модели, либо ввести отдельный «дешёвый».

**Где взять OpenAI API-ключ для embedding?**
Полный гайд — [`docs/openai-key-setup.md`](./openai-key-setup.md). Кратко:
1. Создай аккаунт на [platform.openai.com](https://platform.openai.com/signup)
   (или используй существующий ChatGPT-аккаунт — тот же email/пароль)
2. На [api-keys](https://platform.openai.com/api-keys) → `Create new secret key`
   → скопируй `sk-proj-…`
3. На [billing](https://platform.openai.com/settings/organization/billing)
   положи минимум $5 (хватит на 2 года embedding для одного клиента)
4. Вставь ключ в установщик когда спросит в шаге R1.5

**У меня российская карта — что делать?**
Российские карты (МИР, Visa/Mastercard РФ) **OpenAI не принимает** —
обходного пути нет, нужна зарубежная карта.

Если уже есть карта Казахстана / Армении / Грузии / Турции / ОАЭ /
EU / US — используй её на странице billing OpenAI напрямую.

Если нет — самый быстрый способ выпустить виртуальную зарубежную карту:
[https://t.me/WantToPayBot?start=w17851188--GUSNM](https://t.me/WantToPayBot?start=w17851188--GUSNM) →
выпусти карту (Казахстан/Армения) → пополни рублями (~500₽) →
используй её реквизиты в OpenAI billing. Полный пошаговый гайд
со всеми вариантами — в [`docs/openai-key-setup.md`](./openai-key-setup.md).

**Как сделать чтобы агенты работали как команда в общей TG-группе?**
Это называется **group-mode**. Возможно если установлено ≥2 агентов.
Принцип: все боты сидят в одной общей группе, тегают друг друга
(`@coordinator_bot`, `@marketer_bot` и т.д.) для делегирования.
Полный гайд — `docs/group-mode.md`. Кратко:
1. Через `@BotFather` отключить privacy mode (`/setprivacy → Disable`)
   у каждого бота.
2. Создать TG-группу, добавить ботов как админов.
3. Узнать chat_id через `@username_to_id_bot`.
4. Запустить:
   ```bash
   bash <(curl -fsSL .../install-agents.sh) --enable-group-mode <chat_id>
   ```
   (или согласиться в шаге R5b при свежей установке — там тот же
   мастер).

**А если я хочу только базовую тройку?**
Просто запустите установщик и выберите «2) Base — 3 агента». Но зачем? 🙂
