# 🎓 Гайд куратора — установка OpenClaw + AI-команды (AI TEAM 2.0)

> Для куратора, который ведёт клиентов по установке. Здесь весь путь клиента
> по шагам: что он видит на экране, что это значит и что ему говорить.
> **Актуально на 2026-06-11.** Версии: движок-установщик `2026.06.11`,
> агенты `2026.06.10.3`, тест-драйв `2026.06.10`.


> 🔒 **С 2026-06-14: репозитории закрыты, доставка только через защищённый
> сервер по токену.** Команду установки клиент берёт из **@AITeamVIPBot**.
> Старые команды с `raw.githubusercontent.com` / `releases/...` не работают (404).

---

## 1. Что мы устанавливаем (картина целиком)

Клиент получает **AI-команду в Telegram**: каждый агент — отдельный
Telegram-бот со своим характером и навыками. Под капотом всё работает на
OpenClaw (движок), который ставится на компьютер клиента или на сервер (VPS).

**Три продукта — три токена:**

| Продукт | Токен | Что получает клиент |
|---|---|---|
| Тест-драйв | `TRY-…` | 1 агент, минимум вопросов, бесплатная модель |
| Base | `STD-…` | Движок + **3 агента**: 🔧 Технарь, 📈 Маркетолог, 🎬 Продюсер |
| Pro | `VIP-…` | Движок + **8 агентов** + база знаний (3 базовых + 🎨 Дизайнер, 🧭 Координатор, ✍️ Копирайтер, 💰 Лидоруб, 🎥 Контент-агент) |
| Подписка | `SUB-…` | Только движок, без агентов |

Токен клиент получает **от бота @AITeamVIPBot после оплаты**. По первым
буквам токена сразу видно тариф — это твой первый ориентир в диалоге.

**Главная идея с 2026-06-06: установка = ОДНА команда.** Установщик сам
ставит движок, сам видит тариф в токене и сам доустанавливает нужных агентов.
Никаких «вторых команд» клиенту давать не нужно (кроме особых случаев — ниже).

---

## 2. Главное правило куратора

**Не лечи, пока не понял ситуацию.** Перед любой командой выясни 4 вещи:

1. **Какой продукт?** — спроси первые буквы токена (TRY / STD / VIP / SUB).
   Сам токен целиком пусть НЕ присылает.
2. **Какая система?** — macOS / Windows / Linux-VPS.
3. **На каком шаге застрял?** — пусть назовёт заголовок шага с экрана
   (например «STEP R4: TELEGRAM BOT SETUP»).
4. **Точный текст ошибки** — скрин или копипаста, не пересказ.

Без этих 4 ответов команды не давай. И никогда не проси прислать в чат
API-ключи и токены ботов целиком — по скрину следи, чтобы клиент их не светил.

---

## 3. Что нужно клиенту ДО старта (проговори заранее)

1. **Mac или Windows + 15 минут времени.** На Mac должно быть свободно
   хотя бы 15–20 ГБ на диске.
2. **Telegram-боты через @BotFather.** Один бот = один агент. На Base нужно
   3 токена, на Pro — до 8 (по числу выбранных агентов). Создаются за минуту:
   @BotFather → `/newbot` → имя → получили токен.
   ⚠️ Совет клиенту: создавать ботов **партиями по 2–3 с паузой** — Telegram
   может временно заблокировать создание за «флуд».
3. **Свой Telegram ID** — число. Узнать: написать боту @userinfobot.
4. **Курс-токен** от @AITeamVIPBot (после оплаты).

ChatGPT-аккаунт пригодится **в самом финале**: установщик предложит перевести
всех агентов на GPT-5.5 (Enter = да, вход в браузере). Для самой установки
он не требуется.

## 4. Путь клиента по шагам (macOS / Linux)

### Шаг 1. Команда

Команду установки клиент берёт **из @AITeamVIPBot после оплаты** — она содержит
токен и идёт через защищённый сервер (бот подставляет токен сам):

```bash
COURSE_TOKEN=<ТОКЕН> IP_BASE=https://api.tonytrue.pro/ip bash -c 'bash <(curl -fsSL -H "Authorization: Bearer $COURSE_TOKEN" "$IP_BASE/installers/factory.sh") --course-token "$COURSE_TOKEN"'
```

⚠️ Старые `raw.githubusercontent.com`-команды не работают (репозитории закрыты) —
клиент всегда берёт актуальную команду из бота.

### Шаг 2. Главное меню (если команда без токена)

```
1)  Установить OpenClaw — движок + Telegram-бот  (по умолчанию)
2)  Установить AI-команду агентов — если OpenClaw уже стоит
3)  VPS 24/7 — бот работает, даже когда ноут выключен
```

- Обычный клиент: **просто Enter** (= пункт 1).
- Движок уже стоит, нужны только агенты: пункт 2.
- Хочет на сервер: пункт 3 — установщик напечатает VPS-инструкцию и выйдет.

### Шаг 3. STEP R0: COURSE-TOKEN

Спросит **Telegram ID** (если не определил сам) и проверит токен.
Увидит: `✅ Course-token подтверждён (VIP-тариф)`. Токен сохраняется в кэш —
при повторных запусках вводить не нужно.

Ошибка «несоответствие тарифа» или «токен не подходит» → клиент перепутал
токен (например, TRY-токен в платном установщике) → сверь первые буквы.

### Шаг 4. STEP R1: SYSTEM CHECK

Проверка Node.js / npm / Homebrew / OpenClaw. Чего-то нет — установщик
**сам предложит поставить** (Enter = да). Нужен именно **Node 22**: если у
клиента Node 24 или «системный» Node — установщик предложит перейти на
правильный через nvm, соглашаться.

### Шаг 5. STEP R2: INSTALL OPENCLAW

Ставит/обновляет движок через npm. Идёт 1–3 минуты, бегут строки — это норма.
Долго висит без движения → проблемы с сетью (см. ошибки, `exit=28`).

### Шаг 6. STEP R3: ONBOARDING — НАСТРОЙКА

**Свежая установка:** проходит сама, **без ключей и без вопросов про модели**
(политика 2026-06-11). Модель клиент подключает после установки — финал
покажет команды.

**Установка уже была:** покажет меню «Что делать с существующей установкой?»
— `1) Оставить как есть` (Enter, безопасно) / 2) Сбросить модель на стартовую /
3) Как подключить модель (покажет команды) / 4) Полный сброс. Enter ничего не ломает.

### Шаг 7. STEP R4: TELEGRAM BOT SETUP

Просит **токен главного бота** из @BotFather, потом подтвердить Telegram ID.

⭐ Если Telegram уже был подключён (повторный запуск) — шаг сам пропустится:
`✓ Telegram уже подключён: @имябота — пропускаю`. Токен заново НЕ нужен.

### Шаг 8. STEP R5–R6: ассистент и финал

Создаёт первого ассистента (или пропускает, если уже есть), финальная
проверка, рестарт. Дальше — **главное**:

### Шаг 9. Автопереход к AI-команде (Base/Pro)

Установщик пишет: `✓ Движок и main-агент готовы. Тариф Pro: ставлю твою
AI-команду — это та же установка, НЕ закрывай терминал.`

Появится меню тарифов:

```
1)  OpenClaw   — только движок (без агентов)
2)  Base       — 3 базовых агента
3)  Pro        — 8 агентов (полный набор)  ← рекомендуется
4)  Hermes     — супер-агент над всей командой ★
✓ Твой тариф по токену: Pro — просто нажми Enter.
```

Зелёная строка снизу подсказывает тариф из токена — клиент **просто жмёт
Enter**. Выбрать «выше» своего тарифа нельзя (токен не пустит).

### Шаг 10. Установка агентов (шаги R0–R5 второго установщика)

| Экран | Что происходит | Что говорить клиенту |
|---|---|---|
| R0 АНАЛИЗ | Смотрит, какие агенты уже стоят | Если доустановка — напишет «в системе уже есть: …», это норма |
| **Выбор агентов** (только Pro) | Список 8 агентов с номерами | Ввести номера через пробел («1 2 7») или **Enter = все 8** |
| R1 МОДЕЛЬ | Сообщает «наследуется от системы» — без вопросов | Ничего делать не нужно |
| R1.5 ПАМЯТЬ (embedding) | «Умная память» за ~$15/мес, нужен OpenAI-ключ с зарубежной картой | **Enter = «Нет, без памяти»** (дефолт). Включить можно потом, установку это не ломает |
| R2 TELEGRAM BOT TOKENS | Просит токен бота **на каждого агента** по очереди, проверяет через Telegram | Токены из @BotFather; создавать партиями по 2–3. Если токен уже занят другим агентом — установщик скажет, чьим |
| R3/R4 | Чистка старых (если перезапись) и создание агентов | Просто ждать |
| R4.5 БАЗА ЗНАНИЙ (Pro) | Качает 11 заметок методологии, индексирует | «Твои агенты знают методологию курса» |
| R5 РЕСТАРТ GATEWAY | Перезапуск | Ждать ~30 сек |
| R5b TG-ГРУППА (опц.) | Предложит общий чат команды | По желанию, можно пропустить |

### Шаг 10.5. Финал: предложение мозгов GPT

После установки агентов установщик спросит: **«Перевести всех агентов на
ChatGPT (GPT-5.5)? [Y/n, Enter = да]»**. Enter → откроется браузер, клиент
входит в свой обычный аккаунт ChatGPT — модель сменится у всех агентов сразу.
Отказ — не страшно: позже одной командой `openclaw-add-codex`. Куратор модели
не рекомендует (политика 2026-06-11): клиент волен поставить любую сам —
`openclaw-switch-model <id>`.

### Шаг 11. Проверка результата

Клиент открывает в Telegram любого из своих ботов и пишет `/status`, потом
любой вопрос. Бот ответил — установка завершена. 🎉

## 5. Повторный запуск = безопасный универсальный совет

Если у клиента что-то оборвалось (сеть, закрыл терминал, не доехали агенты):
**«Запусти ту же команду ещё раз и жми Enter по шагам».**

Установщик сам увидит, что уже стоит: движок ✓, Telegram ✓ (пропустит),
ассистент ✓ (пропустит) — и доедет до недостающего. Токен из кэша. Ничего
не ломается и не переспрашивается. Это фикс-команда №1 в 80% обращений.

## 6. После установки: «умные мозги» GPT (опционально)

По умолчанию агенты на бесплатной DeepSeek. Хочет GPT-5.5 — нужен обычный
аккаунт ChatGPT (не API-ключ). Одна команда:

```bash
openclaw-add-codex
```

Она сама ставит плагин, открывает вход через браузер (войти в ChatGPT),
и переключает модель **у всех агентов сразу**. Если после неё какой-то бот
молчит — `openclaw gateway restart` и написать боту `/new`.

Обновить агентов без потери памяти (когда выходит апдейт):

```bash
COURSE_TOKEN=<ТОКЕН> IP_BASE=https://api.tonytrue.pro/ip bash -c 'bash <(curl -fsSL -H "Authorization: Bearer $COURSE_TOKEN" "$IP_BASE/installers/agents.sh") --refresh-templates --course-token "$COURSE_TOKEN"'
```

Память (MEMORY), ответы онбординга (USER) и привязки ботов не трогаются.

## 7. Типовые ошибки → готовые фиксы

| Симптом | Причина | Фикс |
|---|---|---|
| `zsh: parse error near '\n'` | Вставил команду с `<ТОКЕН>` — скобки съел терминал | Дать команду с настоящим токеном, без угловых скобок |
| `command not found: openclaw` | Терминал не видит Node/nvm | Закрыть и открыть Terminal заново → повторить команду. Не помогло → переустановка Node 22 (установщик предложит сам) |
| `curl: (28)` / зависло на сети | Нет доступа к GitHub/Telegram (часто VPN/Wi-Fi) | Ctrl+C → включить/выключить VPN → запустить команду снова |
| Ошибка на «умной памяти» (R1.5) | Старая версия / выбрал «Да» без ключа | Перезапустить установку, на вопросе памяти — Enter («Нет»). В новых версиях это дефолт |
| `Unknown model: opencode/minimax…` | Старое имя модели (провайдер переименован) | `openclaw-switch-model opencode-go/deepseek-v4-flash` |
| «Disable N unavailable skills?» → установка отменилась | Клиент ответил No на вопрос движка | `openclaw doctor --fix --yes` → запустить установку снова (новые версии делают это сами) |
| Бот молчит совсем | Gateway/привязка | `openclaw gateway restart`, подождать 30 сек, написать `/new` |
| Бот отвечает на `/new`, но падает на обычном вопросе («Something went wrong») | Модель/авторизация | `openclaw models status --probe`; чаще всего лечится `openclaw-add-codex` (вход в ChatGPT) или `openclaw-switch-model opencode-go/deepseek-v4-flash` |
| «Этот установщик — второй, OpenClaw не найден» | Запустил установщик агентов без движка | Дать ОДНУ основную команду (раздел 4, шаг 1) |
| Запустил `--collect-debug` / `--diagnose-only` и «ничего не ставится» | Это режимы диагностики, не установка | Установщик теперь сам пишет «⚠ Это НЕ установка»; дать основную команду |
| Mac: «мало места» / нет Xcode CLT | Диск забит / голый Mac | Освободить 15–20 ГБ; `xcode-select --install`; повторить |
| PowerShell ругается на `<` | Windows: команда вставлена не туда | Только Git Bash или WSL/Ubuntu (раздел 8) |

**Если ничего не помогло** — попроси у клиента диагностический архив
(секреты в нём замаскированы автоматически) и передай Антону/технарю:

```bash
COURSE_TOKEN=<ТОКЕН> IP_BASE=https://api.tonytrue.pro/ip bash -c 'bash <(curl -fsSL -H "Authorization: Bearer $COURSE_TOKEN" "$IP_BASE/installers/agents.sh") --collect-debug'
```

Файл появится: `~/openclaw-agents-pack-debug-*.zip`.

## 8. Windows и VPS — коротко

**Windows:** команды те же, но запускать в **Git Bash** (рекомендуем) или
WSL/Ubuntu. В PowerShell — нельзя. Полный гайд: `docs/windows-install-guide.md`.
Частые грабли WSL: gateway требует systemd (`/etc/wsl.conf` → `[boot]
systemd=true`, потом `wsl --shutdown`); если после `wsl --install` пропал
интернет — `ipconfig /flushdns`, `netsh winsock reset`, перезагрузка. Если WSL
старый и systemd не включается — вести клиента на VPS, не мучить.
В финале установки Windows-клиенту предложат **OpenClaw Windows Hub** —
графический интерфейс вместо терминала (опционально, отдельный .exe).

**VPS (бот 24/7 без ноутбука):** пункт 3 главного меню печатает инструкцию.
Суть: арендовать Ubuntu-сервер, зайти по SSH, выполнить ту же команду
с флагом `--vps`. Установщик сам учтёт серверные особенности.

## 9. Команды-памятка куратора

```bash
# Основная установка — клиент берёт готовую команду из @AITeamVIPBot (с токеном).
# Обновление/обслуживание — через сервер с токеном (IP_BASE=https://api.tonytrue.pro/ip):
#   COURSE_TOKEN=<ТОКЕН> IP_BASE=https://api.tonytrue.pro/ip bash -c 'bash <(curl -fsSL -H "Authorization: Bearer $COURSE_TOKEN" "$IP_BASE/installers/agents.sh") --refresh-templates --course-token "$COURSE_TOKEN"' 

# Универсальный фикс: повторить ту же команду установки (ничего не ломает)

# Диагностика (ничего не меняет):
openclaw status
openclaw gateway restart
openclaw models status --probe
openclaw doctor --fix --yes

# Мозги GPT после установки / починка модели:
openclaw-add-codex
openclaw-switch-model opencode-go/deepseek-v4-flash

# Debug-архив для эскалации (через сервер с токеном клиента — см. раздел 7).
```

## 10. Чего куратор НЕ делает

- Не просит прислать API-ключи и токены ботов целиком (по скрину — следит,
  чтобы клиент их замазывал; засветил целиком → посоветовать перевыпустить).
- Не советует «полный сброс», пока не испробован повторный запуск команды.
- Не даёт старые команды «в два шага» из материалов прошлых потоков.
- Не обещает того, чего нет: живые интеграции с CRM и генерация видео
  у Лидоруба/Контент-агента — «подключается позже», агенты сами это честно
  говорят.

> Расширенная версия с деталями для сложных случаев — `docs/curator-guide.md`
> в репозитории openclaw-agents-pack (раздел 5: все известные ошибки).
