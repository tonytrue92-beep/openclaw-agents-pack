# Путь клиента в установщике AI TEAM 2.0

> ⚠️ **Документ отстал от прода на несколько волн** (актуальная версия —
> 2026.06.10): дефолт-модель теперь бесплатная minimax (не codex), на Pro
> есть **экран выбора агентов** (до 8, Enter = все), меню показывает 8 ролей,
> бот-токенов спрашивается по числу выбранных. Актуальный путь — в
> [`curator-guide.md`](./curator-guide.md). Этот файл — раскадровка wave 26,
> полезен как референс формулировок.

**Версия:** v2026.05.25.4 (wave 26)
**Дата:** 2026-05-25

Это полный список **всех экранов и фраз** которые видит клиент при
установке AI-команды. Каждый блок содержит:
- 🎬 **Что видит клиент** (фактический текст)
- 📍 **Где править** (`файл:строка` — открыл, отредактировал, сделал коммит)

После любой правки → `bash scripts/update-checksums.sh` + bump
`INSTALLER_VERSION` + commit → release-workflow выкатит обновление.

## 🎬 ШАГ 0 — Запуск команды

Клиент копирует команду из Телеграма в Терминал и нажимает Enter:

```bash
bash <(curl -fsSL https://github.com/tonytrue92-beep/openclaw-agents-pack/releases/latest/download/install-agents-bundled.sh)
```

Дальше всё **на стороне установщика** — клиент только наблюдает и
выбирает опции.

📍 *Эта команда — то что ты пересылаешь в Телеграме клиенту. Текст команды
не в коде — он в твоих готовых сообщениях.*

### 🎬 V0 — Если токен невалиден (3 попытки)

После 3-х неудачных попыток — red-block:

```
╔════════════════════════════════════════════════════════════════╗
║                                                                ║
║   ✗  УСТАНОВКА ОТКЛОНЕНА — курс-токен не валиден              ║
║                                                                ║
╚════════════════════════════════════════════════════════════════╝

   Что произошло:
   • Ты не ввёл токен (или ввёл пустую строку), либо
   • Токен не прошёл проверку (отозван / битая подпись / другой TG)

   Что делать:
   1. Открой @AITeamVIPBot в Telegram
   2. Напиши /start
   3. Введи email или телефон которыми оплачивал курс
   4. Бот пришлёт новый токен вида OC5-STD-... или OC5-VIP-...
   5. Скопируй ВЕСЬ токен (часто длинная строка) и запусти установщик снова

   Если бот говорит «email не найден»:
   • Проверь что вводишь email с которого реально оплачивал
   • Возможно оплата ещё не дошла до базы (до 30 минут)
   • Если уверен что оплачивал — пиши в саппорт-чат курса

   Если используешь токен с другого Telegram-аккаунта:
   • Токены привязаны к TG (анти-шаринг). С чужим TG не работают.
   • Открой @AITeamVIPBot с ТОГО ЖЕ аккаунта что используешь сейчас.
```

**Где править**: `scripts/install-agents.sh:720-748`

```
   Что произошло:
   Ты выбрал Pro (8 агентов), но твой токен — STD-тарифа.

   Что делать:
   • Если ты оплачивал Pro — получи новый токен:
     @AITeamVIPBot → /start → email/телефон оплаты
```

```
╔════════════════════════════════════════════════════════════════╗

   Апгрейд на Base (3 агента) или Pro (8 агентов) — пиши в саппорт-чат курса.
   После апгрейда получишь новый токен в @AITeamVIPBot и запустишь этот
   установщик снова — он распознает новый тариф и поставит агентов.
```

## 🎨 Цвета (ANSI escape codes)

В коде используются переменные с цветами — не редактируй их сами:

| Переменная | Цвет |
|---|---|
| `${BOLD}` | жирный текст |
| `${DIM}` | приглушённый текст |
| `${WHITE}` | белый |
| `${GREEN}` | зелёный |
| `${YELLOW}` | жёлтый |
| `${RED}` | красный |
| `${CYAN}` | голубой |
| `${MAGENTA}` | пурпурный |
| `${NC}` | сброс цвета (обязательно после цветного блока!) |

Пример:
```bash
echo -e "   ${BOLD}${WHITE}Какой-то текст${NC}"
#         ^   ^      ^      ^               ^
#         |   |      |      |               сброс цвета
#         |   |      |      сам текст (редактируй здесь)
#         |   жирный белый
#         отступ
```
