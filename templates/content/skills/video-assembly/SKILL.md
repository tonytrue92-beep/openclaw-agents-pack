# Video Assembly — сценарий и сборка ролика воедино

Связываю всё в готовое видео: пишу сценарий и раскадровку, собираю
картинки (`image-generation`), видео-сцены (`video-hyperframes`) и
озвучку (`voiceover-elevenlabs`) в короткий или длинный ролик.

## Когда использую

- Нужно из идеи сделать ролик «под ключ» (сценарий → кадры → озвучка → сборка)
- Нужно свести уже готовые куски (картинки + аудио) в один файл
- Нужна раскадровка под Reels/Shorts/YouTube

## Когда НЕ использую

- Нужна только картинка → `image-generation`
- Нужна только озвучка → `voiceover-elevenlabs`
- Нужны продающие смыслы для сценария → сначала к Маркетологу/Копирайтеру

## Структура, с которой работаю

**Короткое видео (Reels/Shorts, 15-60 сек):**
1. Хук (0-3 сек) — зацепить
2. Суть (основная мысль, 1-2 кадра)
3. CTA (что сделать дальше)

**Длинное видео (YouTube):**
- Вступление → блоки по теме → вывод → CTA. Каждый блок — сцена + озвучка.

## Раскадровка (формат)

Для каждой сцены: № → что в кадре (картинка/видео) → текст на экране →
озвучка → длительность.

## Мой flow

1. Уточняю формат и длительность (из `USER.md` / у тебя)
2. Пишу сценарий + раскадровку → согласую с тобой
3. Генерирую кадры (`image-generation`), сцены (`video-hyperframes`),
   озвучку (`voiceover-elevenlabs`)
4. Свожу в ролик нужного формата (вертикаль/горизонталь, длительность)
5. Отдаю файл; что зашло — пишу в `MEMORY.md`

## Готовность

Сценарий и раскадровку делаю всегда. Рендер видео и озвучка — по
подключённым сервисам (Hyperframes/HeyGen, ElevenLabs). Нет ключей —
отдаю сценарий + раскадровку + список «что подключить», без обмана «готово».

## OpenClaw ограничения

Финальный файл — в разрешённую папку (`~/.openclaw/media/`,
`~/.openclaw/agents/`, `/tmp`), иначе Telegram не отправит.

## Главное

Я — «режиссёр»: связываю картинку, видео и звук по сценарию. Сначала
сценарий и согласование, потом сборка. Не выдаю раскадровку за готовый ролик.
