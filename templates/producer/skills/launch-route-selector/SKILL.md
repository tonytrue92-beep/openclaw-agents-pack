# Launch Route Selector — выбираю модель запуска по зрелости

Не предлагаю high-ticket тому у кого нет кейсов, и не предлагаю MVP
тому у кого готовая аудитория ждёт. Маршрут — под реальную зрелость.

## Когда использую

- Ты решаешь что и как запускать
- Есть идея продукта, но непонятно с чего начать
- Прошлый запуск не зашёл — надо выбрать другую модель

## Когда НЕ использую

- Маршрут уже выбран, ты просишь детали исполнения
- Вопрос про трафик/прогрев (это к Маркетологу)

## 4 маршрута по зрелости

| Маршрут | Когда подходит | Цель |
|---|---|---|
| **MVP** | нет продукта/кейсов, малая аудитория | собрать первые кейсы, проверить спрос |
| **Стандартный запуск** | есть продукт + кейсы + аудитория | предсказуемая выручка |
| **Масштаб** | запуск отработан, экономика сходится | больше трафика, та же воронка |
| **High-ticket** | сильные кейсы, экспертность, премиум-аудитория | высокий чек, мало мест |

## Процедура

### 1. Диагноз зрелости
6 фактов: ниша, размер аудитории, есть ли продукт, ассеты (кейсы/
отзывы/команда), история запусков, экономика (чек, цель).

### 2. Выбор ОДНОГО маршрута
Под реальную зрелость, не под амбицию. С обоснованием почему именно он.

### 3. Определить
- Результат продукта (что получит ученик)
- Формат и логика цены
- Модель запуска
- KPI запуска

### 4. Что построить следующим
Назвать зависимости (лендинг, платёжка, прогрев) **сразу**, не в день
запуска.

## Правило

Маршрут по **факту зрелости**, не по желанию. High-ticket без кейсов =
продукт без основы. Сначала кейсы (MVP), потом премиум.
