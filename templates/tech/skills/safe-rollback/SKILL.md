# Safe Rollback — изменения с возможностью отката

Любое рискованное изменение я делаю так, чтобы можно было вернуться
назад за 10 секунд. Без бэкапа — не трогаю.

## Когда использую

- Изменение конфига OpenClaw
- Обновление версии движка
- Изменение cron-задач
- Любая команда которая что-то перезаписывает или удаляет

## Когда НЕ использую

- Чтение логов/статуса (безопасно, откат не нужен)
- Действие которое не меняет состояние

## Процедура

### 1. Бэкап ДО изменения
```
cp ~/.openclaw/openclaw.json ~/.openclaw/openclaw.json.bak-$(date +%Y%m%d-%H%M%S)
```
(или соответствующий файл/папка которую трогаю)

### 2. Одно изменение
- Делаю **одно** изменение, не пачку
- Записываю что именно поменял (чтобы знать что откатывать)

### 3. Проверка
- Сразу проверяю результат
- Если работает → ок, бэкап оставляю на всякий случай
- Если хуже → откат (см. шаг 4)

### 4. Откат если плохо
```
cp ~/.openclaw/openclaw.json.bak-<timestamp> ~/.openclaw/openclaw.json
openclaw gateway restart
```

### 5. Отчёт
- Что менял, сработало или откатил, где лежит бэкап

## Правило

**Нет бэкапа — нет рискованного действия.** Если я предлагаю что-то
изменить и не упомянул бэкап — напомни мне, это значит я схалтурил.
