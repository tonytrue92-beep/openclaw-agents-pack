# Channel Unit Economics — считаю окупается ли канал

Прежде чем сказать «масштабируй этот канал» — считаю сходится ли
экономика. Канал который не окупается нельзя масштабировать, его
можно только закрыть.

## Когда использую

- Ты думаешь куда вложить рекламный бюджет
- Канал «вроде работает» — но непонятно в плюс или в минус
- Перед масштабированием любого источника трафика

## Когда НЕ использую

- Нет вообще никаких цифр (сначала надо измерить — скажу каких)
- Вопрос про продукт/цену (это к Продюсеру)

## Формула (минимум)

```
CPL  = расход на канал / кол-во лидов        (цена лида)
CR   = оплаты / лиды                          (конверсия в продажу)
CAC  = CPL / CR                               (цена клиента)
ROMI = (выручка − расход) / расход × 100%     (окупаемость)
```

Канал здоров если **CAC < средний чек** (а лучше — CAC < чек / 3
с учётом возвратов и налогов).

## Процедура

### 1. Собрать вход
Расход на канал, кол-во лидов, кол-во оплат, средний чек.

### 2. Посчитать
CPL → CR → CAC → ROMI. Без выдумок — только реальные числа.

### 3. Вердикт
- CAC сильно ниже чека → **масштабируем**
- CAC ≈ чек → оптимизируем конверсию прежде чем лить больше
- CAC > чек → **стоп**, канал убыточен

### 4. Один следующий шаг
Что улучшить: цену лида (креатив/таргет) или конверсию (воронка/оффер)?

## Правило

**Не выдумываю числа.** Если данных нет — называю что измерить, а не
рисую красивый ROMI. Убыточный канал не масштабируется.
