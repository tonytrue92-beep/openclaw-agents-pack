# Бриф боту @AITeamVIPBot — ОДНА команда установки (платный поток)

**Обновлено:** 2026-06-06. Связано: установщики уже на `2026.06.06` (в проде).

## Что изменилось
Платный установщик объединён: **factory сам дотягивает агентов** по тарифу из
токена. Значит бот должен слать **одну** команду вместо двух.

## Что сделать в боте
1. После выдачи токена слать **единственную** команду с уже подставленным токеном
   (клиент не вводит токен руками):
   ```
   bash <(curl -fsSL https://raw.githubusercontent.com/tonytrue92-beep/openclaw-factory/main/scripts/demo-install.sh) --course-token <ВЫДАННЫЙ_ТОКЕН>
   ```
   - **VIP / STD** → движок + агенты доустановятся сами (Pro = 8 + база знаний, Base = 3).
   - **SUB** → та же команда, поставится только движок (агенты не нужны).
2. **Убрать** из сообщений «теперь запусти вторую команду …» — второй команды больше нет.
3. **Windows-подсказка (опц.):** в Windows-инструкции добавить строку
   «в конце установщик предложит удобный интерфейс (Companion) — соглашайся».
4. **Тест-драйв** — команда без изменений (она и так одна):
   ```
   bash <(curl -fsSL https://raw.githubusercontent.com/tonytrue92-beep/openclaw-test-drive/main/scripts/install-trial.sh) --token <TRY_ТОКЕН>
   ```

## Важно (совместимость)
- Токен-ключ Ed25519, payload-префиксы (VIP/STD/SUB/TRY) — **без изменений**.
- Старые отдельные команды продолжают работать (перезапуск / `--refresh-templates`),
  но клиенту теперь шлём **одну**.
- Токен в команде безопасно подставлять — это ровно то, что клиент запускает;
  агенты ставятся в той же сессии (внутри код токен в командной строке НЕ светит —
  опирается на локальный кэш).

## Заодно (если уже трогаешь выдачу токена)
Когда поднимем аналитику установок — на этом же шаге выдачи бот должен слать
`POST /issue` с email (см. отдельный бриф `install-analytics-bot-brief.md`).
