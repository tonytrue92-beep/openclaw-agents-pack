# Бриф технарю — обновить install-команды и инфо в @AITeamVIPBot

## Задача

Обновить то, что бот присылает клиенту **после выдачи токена**: актуальные
ссылки + уже подставленный токен + ПРАВИЛЬНАЯ инфа «что понадобится» (она
поменялась — платный установщик теперь логинится через ChatGPT, а не через
API-ключ).

## Золотое правило: НЕ вшивать номер версии в URL

Используем ссылки, которые **сами отдают последнюю версию** — тогда бот не
придётся править при каждом релизе:

| Что | URL (всегда свежак) | Почему такой |
|----|--------------------|-------------|
| Движок (1 ступень, платный) | `https://raw.githubusercontent.com/tonytrue92-beep/openclaw-factory/main/scripts/demo-install.sh` | `/main/` = последний коммит; скрипт самодостаточный |
| Агенты (2 ступень, платный) | `https://github.com/tonytrue92-beep/openclaw-agents-pack/releases/latest/download/install-agents-bundled.sh` | `releases/latest` = последний релиз; **bundled** (самодостаточный) |
| Тест-драйв (TRY) | `https://raw.githubusercontent.com/tonytrue92-beep/openclaw-test-drive/main/scripts/install-trial.sh` | `/main/` = последний коммит; скрипт самодостаточный |

⚠️ **Важно про agents-pack:** только `releases/latest/.../install-agents-bundled.sh`.
НЕ `raw .../main/scripts/install-agents.sh` — он не самодостаточный (подключает
`lib/*.sh`, которых нет при запуске через `curl`). factory и trial — наоборот,
берём `raw /main/` (они одним файлом).

## Токен подставляем сразу (бот его знает)

Не «вставь токен когда попросит», а сразу в команду:

- **Тест-драйв (TRY-токен):** флаг `--token <ТОКЕН>`
- **Платные (SUB / STD / VIP / HRM):** флаг `--course-token <ТОКЕН>` (на обеих ступенях)

## Что понадобится клиенту (ВАЖНО — поменялось)

**Платные тарифы (SUB/STD/VIP/HRM):**
- 🧠 **Аккаунт ChatGPT** — мозги агента. Бесплатного достаточно; ChatGPT Plus
  ($20/мес) — умнее. Установщик сам запустит вход (на шаге «мозги» покажет
  ссылку/код — клиент открывает её и логинится в ChatGPT). **API-ключ больше
  НЕ нужен** (раньше просили opencode.ai — теперь нет).
- 🤖 **Токен Telegram-бота** из @BotFather (`/newbot`).

**Тест-драйв (TRY):**
- 🧠 **Бесплатный ключ opencode.ai** — мозги (модель DeepSeek Free, карта не
  нужна). Установщик откроет opencode.ai и попросит вставить ключ.
- 🤖 **Токен Telegram-бота** из @BotFather.

## Готовые сообщения бота (подставить реальный токен вместо <ТОКЕН>)

### A. После оплаты тест-драйва (TRY-токен)

```
Готово ✅ Доступ к тест-драйву AI TEAM 2.0.

Открой Терминал (на Mac: Cmd+Пробел → «Терминал») и вставь:

bash <(curl -fsSL https://raw.githubusercontent.com/tonytrue92-beep/openclaw-test-drive/main/scripts/install-trial.sh) --token <ТОКЕН>

Что понадобится по ходу:
• бесплатный ключ opencode.ai (установщик откроет сайт — это «мозги»)
• токен бота из @BotFather
```

### B. Платный тариф (SUB / STD / VIP / HRM) — 2 шага

```
Готово ✅ Твой доступ к AI TEAM 2.0. Ставим в 2 шага.

ШАГ 1 — движок (вставь в Терминал, дождись «готово»):

bash <(curl -fsSL https://raw.githubusercontent.com/tonytrue92-beep/openclaw-factory/main/scripts/demo-install.sh) --course-token <ТОКЕН>

ШАГ 2 — твои AI-агенты (когда первый закончит):

bash <(curl -fsSL https://github.com/tonytrue92-beep/openclaw-agents-pack/releases/latest/download/install-agents-bundled.sh) --course-token <ТОКЕН>

Что понадобится по ходу:
• аккаунт ChatGPT — это «мозги» (бесплатного хватит; ChatGPT Plus $20 — умнее).
  На шаге «мозги» установщик покажет ссылку для входа — открой её и войди в ChatGPT.
• токен бота из @BotFather (для VIP — несколько ботов).
```
